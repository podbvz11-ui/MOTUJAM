# MOTUJAM (모투잼)

SOOP 스트리머 **모치**의 노래 클립으로 만든 비영리 팬메이드 리듬 게임입니다.
노트가 위에서 아래로 떨어지는 4키 / 6키 방식이며, 35곡 × 5단계 난이도(Easy ~ Extreme)가 들어 있습니다.

## 내려받기

오른쪽 **Releases** 에서 `MOTUJAM_v1.0_Windows.zip` 을 받아 압축을 풀고 `MOTUJAM.exe` 를 실행하세요. (Windows 64비트)

압축을 푼 폴더를 통째로 두어야 합니다. exe 만 따로 옮기면 실행되지 않습니다.

## 조작

| 화면 | 키 |
|---|---|
| 4키 | `A` `S` `;` `'` |
| 6키 | `A` `S` `D` `L` `;` `'` |
| 곡 선택 | `↑↓` 곡, `←→` 키 수 / 난이도, `ENTER` 시작, `ESC` 타이틀 |
| 설정 | `F1/F2` 노트 속도, `F3/F4` 판정 보정, `F6` 배경 영상 |
| 플레이 | `ESC` 일시정지 |
| 타이틀 | `ESC` 게임 끝내기 |

노트가 음악보다 빠르거나 느리게 느껴지면 곡 선택 화면에서 `F3` / `F4` 로 판정 보정값을 바꿔 보세요.
스피커·헤드폰·블루투스에 따라 소리가 나오는 시간이 다릅니다.

## 안내

- 방송 클립 영상에서 따온 음악이라, 노래 시작 전과 끝난 후에 스트리머의 말소리가 나올 수 있습니다.
- 채보는 음원을 분석해 자동으로 만든 것이라 박자가 완벽하지 않습니다. 감안하고 즐겨주세요.
- 판정 범위: PERFECT ±45ms / GREAT ±90ms / GOOD ±135ms

## 이 저장소에 들어 있는 것

Unity 프로젝트의 소스입니다 (Unity 6000.6).

| 폴더 | 내용 |
|---|---|
| `Assets/Scripts` | 게임 코드 (UI 는 모두 코드로 만듭니다) |
| `Assets/StreamingAssets/Skin` | 게임이 읽는 이미지 |
| `Assets/StreamingAssets/Songs` | 곡마다의 채보(`song.json`)와 자켓 |
| `SkinSource~` | 이미지 원본 |
| `Tools~` | 채보 생성 도구 (Python) |

곡의 **음원과 영상은 저장소에 없습니다.** 용량과 저작권 때문에 릴리스의 게임 zip 에만 들어 있습니다.
소스로 직접 실행하려면 릴리스 zip 의 `MOTUJAM_Data/StreamingAssets/Songs` 폴더를 `Assets/StreamingAssets/Songs` 에 덮어쓰세요.

### 곡 추가하기

`Assets/StreamingAssets/Songs/<곡 이름>/` 폴더에 아래 파일을 넣으면 곡 선택 화면에 나옵니다.

- `song.json` — 제목, BPM, 채보
- `audio.ogg` — 음원
- `jacket.jpg` — 자켓 (선택)
- `video.mp4` — 배경 영상 (선택)

채보의 노트는 `{ "t": 시각(ms), "lane": 레인 번호(0부터), "len": 롱노트 길이(ms, 없으면 생략) }` 형식입니다.
